# Homebrew tap for Sharqey

```sh
brew install sharqey/tap/sharqey          # CLI
brew install --cask sharqey/tap/sharqey   # desktop app (macOS)
```

Formulae are updated automatically on each release of
[sharqey/cli](https://github.com/sharqey/cli) and
[sharqey/desktop](https://github.com/sharqey/desktop).
